# つぎて帳　3分デモの台本

> **1人・1場面・前後**で組む。主役は町に来て1年目の研修生、青木さん（架空・29歳）。
> 場面は「畑で迷った朝」。かぼちゃのとりどきは近い人の言葉で分かる。石灰の量は、まだ誰も話していない。答えを作らずに1人に聞き、答えがノートに残り、次の人は二度聞かない。この往復を見せる。
> 機能は、この場面の中で出てくる順にしか見せない。人名・地名・数字はすべて架空のデモデータ（「新規参入者の56.0%」だけは公表資料）。

## 人と場面

- **青木さん**（架空・29歳）：南川町に来て1年目。川端さんの所で研修中
- **川端さん**（架空・66歳）：研修先。オクラとピーマン
- **山野さん**（農業50年）・**大西さん**（60年・上原地区）：「地域の新人にも」と言葉を見せている農家さん

## 撮る前の準備

- [ ] `npm start` → 入口 `http://localhost:8793/` の「**撮影用：最初の状態にして3つを並べる**」を押す（確認のダイアログは出ない。`http://localhost:8793/?shoot=1` を開いても同じ）
  - 青木さんのノートは **29 行**、石灰の答えはまだ無い、にんにくは前から「聞ける人がいない」、の状態に毎回そろう（用意した話は Claude を呼ばず決まった規則で整理するので、何度戻しても同じ）
  - 並ぶ画面は左から 青木さん／川端さん／町の担当者。上の「真ん中を大西さんにする」で、真ん中だけ大西さんに替わる（左右は読み込み直さない）
- [ ] パソコンの画面幅は 1300px 以上（3つが横に並ぶ）。ブラウザの拡大は 100%
- [ ] 0:00 の畑の絵は、入口の上の絵（野帳とスマホの手元・候補3枚から選んだ）を使う（入口を開いた状態から撮り始める）
- [ ] 押す前の確かめ：Playwright が入っていれば `node scripts/walkthrough.cjs` で、台本の順に自動で押して場面ごとの画像が `tmp/walkthrough/` にできる
- [ ] 各画面の右上：ふだんは「整理：Claude」。AI が働いた直後だけ、少しのあいだ「照合：Claude Opus 5.5」のように役とモデルが出る。キーを入れる前に撮るなら「照合：見本（未接続）」と出るので、字幕のモデル名は外す
- [ ] 声：実機のマイクで撮れるなら本人役が話す。撮れなければ「見本の話を入れる（声の代わり）」を押し、字幕「デモ用：声の代わりに見本の話を入れています」を出す
- [ ] 読み上げの音を録るなら、パソコンの音も録る設定にする

| 時間 | 画面 | 操作 | 語り | 字幕 |
|---|---|---|---|---|

| 0:20–0:45 | 青木さん「質問する」 | 見本の「かぼちゃはいつとればいいですか？」→「聞く」（答えは入力欄の上に出る）→ 大西さんの行の「ノートで見る」 | AI は答えを作らない。近い人の言葉を、理由つきで並べる。同じ地区の山野さん、上原の大西さん。「上原は冷えるのが早いけん、一週間は早よとる」。場所で違うことも、本人の言葉で分かる。 | 答えは本人が話した行だけ（照合：Claude Opus） |

- 2:25 の前後は、0:00 と同じ「引き継ぎノート」の画面で、上の数（**29 → 31 行・今日 +2**）を見せる。かぼちゃの欄は 7 行のまま変わらないので、増えた所は「畑全体」で見せる（石灰の答えは作物の名前が無い話なので「畑全体」に入る）。
- 聞き返しは大西さんの場面だけで出る。川端さんの「一反に一袋半」には、聞き返すあいまいな言葉が無い。
- Claude が働く瞬間だけ字幕1行「役：モデル（型）」。説明の場面は作らない。

## 言わないこと

- 農業のやり方の正しさ（「一反に一袋半が正しい」などとは言わない。画面の言葉は架空の人の話）
- 冒頭の 56.0% 以外の数字を事実として言わない。ほかの数は字幕で「架空のデモ」と断る。効果の数（○件→○件）は出さない
- 「AI が最適な答えを出す」（出すのは、いちばん近い人の言葉）
- 現場の方の協力は、了承をもらう前に「協力済み」「導入予定」と言わない

## 時間が余ったとき・質問されたときの予備

- **健太さんの画面**（家を継ぐ人）：家族だけの話（山野さんの腰の話）も見える。見せる範囲が人によって違うことを示せる
- **本人の「話したこと」**：あとから見せる範囲を変えられる
- **作業カード**：本人が話すと「明日」「土曜」など話した言葉から作業カードができ、急ぐ順に並ぶ。「健太、土曜に軽トラ出してくれ」は健太さんへの頼みごとのカードになる
- **Claude の使い方**：Claude には印を付けさせ、行の番号を選ばせるだけ。画面の言葉は必ず本人の文そのもの。返ってきた番号や期限が手元に無ければ捨てる（README「Claude の使い方」）
