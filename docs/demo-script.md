# つぎて帳　3分デモの台本

> 主役は**新しく農業を始めた人（継ぐ人）**。目線は最初から最後まで、研修生の青木さん（架空）に置く。
> 人名・地名・数字はすべて架空のデモデータ（「新規参入者の56.0%」だけは公表資料）。

## 伝えたいこと（3つだけ）

1. **聞けば、近い人の言葉がすぐ出る**（AI は答えを作らない。誰が・どこで・いつ言ったかつき）
2. **無ければ、いちばん近い農家さん1人だけに聞く**。答えはノートに入り、二度聞かなくていい
3. **だれに見せるかは話した本人が決める**。町には数だけ届き、足りない分野が見える

## 撮る前の準備

- [ ] `npm start` → 入口 `http://localhost:8793/` の「最初の状態に戻す」を押す
- [ ] パソコンでは入口の「3つを並べて見る」（左から 青木さん／川端さん／町の担当者）を全画面にする。ブラウザの拡大は 100%
- [ ] 大西さんの画面（入口の「大西さんの画面」）を別のタブで開いておく（2:10 の場面で使う）
- [ ] 画面右上が「整理：Claude」になっているか確かめる（キーを入れる前に撮るなら「整理：見本」のまま撮り、字幕で断る）
- [ ] 声：実機のマイクで撮れるなら本人役が話す。撮れなければ「見本の話を入れる（声の代わり）」を押し、字幕「デモ用：声の代わりに見本の話を入れています」を出す
- [ ] 読み上げの音を録るなら、パソコンの音も録る設定にする

## 言わないこと

- 農業のやり方の正しさ（「一反に一袋半が正しい」などとは言わない。画面の言葉は架空の人の話）
- 裏の取れない数字（「○兆円の効果」「3割が離農」など）
- 「AI が最適な答えを出す」（出すのは、いちばん近い人の言葉）

## 時間が余ったとき・質問されたときの予備

- **健太さんの画面**（家を継ぐ人）：家族だけの話（山野さんの腰の話）も見える。見せる範囲が人によって違うことを示せる
- **本人の「話したこと」**：あとから見せる範囲を変えられる
- **作業カード**：本人が話すと「明日」「明後日」「土曜」など話した言葉から作業カードができ、急ぐ順に並ぶ。「健太、土曜に軽トラ出してくれ」は健太さんへの頼みごとのカードになる
- **Claude の使い方**：Claude には印を付けさせ、行の番号を選ばせるだけ。画面の言葉は必ず本人の文そのもの。返ってきた番号や期限が手元に無ければ捨てる（README「Claude の使い方」）
